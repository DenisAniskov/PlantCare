🎉 DESKTOP ВЕРСИЯ ГОТОВА К РАБОТЕ!

══════════════════════════════════════════════════════════════
   📌 СПОСОБ 1: MSI ИНСТАЛЛЯТОР (РЕКОМЕНДУЕТСЯ!)
══════════════════════════════════════════════════════════════

   ✅ Самый простой и удобный способ!

   1. Откройте папку:
      desktop\build\compose\binaries\main-release\msi\

   2. Двойной клик на файл:
      PlantCare-0.1.0.msi

   3. Установите как обычную программу

   4. Готово! PlantCare появится в меню Пуск

══════════════════════════════════════════════════════════════
   ⚡ СПОСОБ 2: BAT-ФАЙЛ (БЫСТРЫЙ ЗАПУСК)
══════════════════════════════════════════════════════════════

   ✅ Просто дважды кликните на файл:
   
      PlantCare-Desktop.bat
   
   (находится в корне проекта)

   Скрипт автоматически запустит приложение!

══════════════════════════════════════════════════════════════
   🎯 СПОСОБ 3: ПРЯМОЙ ЗАПУСК EXE
══════════════════════════════════════════════════════════════

   1. Откройте папку:
      desktop\build\compose\binaries\main-release\exe\

   2. Двойной клик на:
      PlantCare-0.1.0.exe

   3. Создайте ярлык на рабочем столе для удобства!

══════════════════════════════════════════════════════════════
   🛠️ СПОСОБ 4: РАЗРАБОТКА
══════════════════════════════════════════════════════════════

   Для разработчиков - запуск без сборки:

      ./gradlew :desktop:run

══════════════════════════════════════════════════════════════
   ❓ РЕШЕНИЕ ПРОБЛЕМ
══════════════════════════════════════════════════════════════

   Проблема: "EXE не открывается"
   Решение: Используйте MSI инсталлятор (Способ 1)

   Проблема: "Файлы не найдены"
   Решение: Запустите PlantCare-Desktop.bat
            (он автоматически соберёт приложение)

   Проблема: "Ошибка при запуске"
   Решение: Откройте INSTALL-DESKTOP.md
            (там есть подробные инструкции)
