# 🖥️ PlantCare Desktop - Инструкция по установке

## 🚀 Способы запуска Desktop версии

### Способ 1: MSI Инсталлятор (Рекомендуется) ✨

**Самый простой способ!** Установите приложение как обычную Windows программу:

1. Найдите файл инсталлятора:
   ```
   desktop\build\compose\binaries\main-release\msi\PlantCare-0.1.0.msi
   ```

2. **Двойной клик** на файл `PlantCare-0.1.0.msi`

3. Следуйте инструкциям мастера установки

4. После установки PlantCare появится:
   - В меню "Пуск" 
   - На рабочем столе (опционально)
   - В списке установленных программ

5. Запускайте как обычное приложение!

### Способ 2: Bat-файл для быстрого запуска ⚡

Создан удобный `.bat` файл для запуска:

1. **Двойной клик** на файл `PlantCare-Desktop.bat` в корне проекта

2. Скрипт автоматически:
   - Найдёт exe файл
   - Запустит приложение
   - Или соберёт его, если нужно

### Способ 3: Прямой запуск EXE 🎯

Если хотите запустить напрямую:

1. Перейдите в папку:
   ```
   desktop\build\compose\binaries\main-release\exe\
   ```

2. Запустите:
   ```
   PlantCare-0.1.0.exe
   ```

3. **Создайте ярлык** для удобства:
   - Правый клик на `PlantCare-0.1.0.exe`
   - "Создать ярлык"
   - Перетащите ярлык на рабочий стол

### Способ 4: Сборка из исходников 🛠️

Если нужно пересобрать:

#### Собрать EXE:
```bash
./gradlew :desktop:packageReleaseExe
```

#### Собрать MSI:
```bash
./gradlew :desktop:packageReleaseMsi
```

#### Запустить без сборки (dev режим):
```bash
./gradlew :desktop:run
```

## 🔧 Решение проблем

### Проблема: "Приложение не запускается"

**Решение 1**: Установите через MSI инсталлятор (способ 1)

**Решение 2**: Проверьте Java:
```bash
java -version
```
Должна быть Java 17 или выше.

**Решение 3**: Пересоберите приложение:
```bash
./gradlew clean
./gradlew :desktop:packageReleaseMsi
```

### Проблема: "Окно открывается и сразу закрывается"

Это может быть проблема с GPU. В конфигурации уже включен программный рендеринг:
```
-Dskiko.renderApi=SOFTWARE
```

Если проблема сохраняется, запустите через командную строку для просмотра ошибок:
```bash
cd desktop\build\compose\binaries\main-release\exe\
PlantCare-0.1.0.exe
```

### Проблема: "MSI не устанавливается"

Убедитесь, что WiX Toolset установлен. Gradle автоматически скачает его, но если нужно:
- Запустите сборку снова
- Проверьте права администратора
